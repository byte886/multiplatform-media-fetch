# multiplatform-media-fetch

下载 YouTube / 哔哩哔哩 / 抖音音视频，优先字幕、无字幕时本地离线转写（SenseVoice+FunASR），非中文翻译为中文并按作者角色梳理成文章，支持同系列批量与分章节编排。

## 使用

这是豆包（及兼容 Agent）的**本地技能（Skill）**。完整能力、触发场景与操作流程见入口文档 **[`SKILL.md`](SKILL.md)**，Agent 命中时首先读取它；下列子目录按需加载，不必一次全读。

## 目录

- `SKILL.md`：技能入口与路由
- `references/`：按需细读的参考文档
- `scripts/`：随技能分发的可执行脚本
