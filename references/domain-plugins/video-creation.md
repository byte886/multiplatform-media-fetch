# 行业插件：视频创作/生成类

> 通用镜头拆解维度，适用于所有做视频、AI生成视频、影视分析类内容。

---

## 自动提取的核心维度

### 1. 逐镜头拆解
每个镜头自动记录：
| 维度 | 说明 |
|---|---|
| 景别 | 远景/全景/中景/近景/特写 |
| 运镜 | 推/拉/摇/移/跟/环绕/升降/手持 |
| 时长 | 这个镜头持续多久 |
| 转场 | 硬切/擦镜/匹配剪辑/淡入淡出/甩镜 |
| 构图 | 中心构图/三分法/对称/前景遮挡 |
| 光线 | 顺光/逆光/侧光/自然光/人造光 |
| 色温 | 暖调/冷调/高对比/低饱和 |

### 2. 节奏与情绪
- 整体节奏：快剪/慢镜头/卡点
- 情绪弧线：开场hook→展开→高潮→结尾CTA
- 音乐风格：BGM类型、卡点位置

### 3. AI提示词反推
从拆解的镜头自动生成可复用的AI视频提示词：
```
[景别]+[运镜]+[主体]+[场景]+[光线]+[转场]
示例：缓慢推镜头，近景，戴翡翠的手放在丝绒布上，侧光，暖色温，2秒
```

---

## 关键帧抽取策略
视频创作类的关键帧要比普通内容更密：
- 每个镜头至少抽1帧（因为每个镜头都是不同的运镜/构图）
- 优先选镜头中间帧（避免转场模糊）
- 用拉普拉斯清晰度评分避免运动模糊的帧
