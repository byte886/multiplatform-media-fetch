# 视频效果分析（效果呈现层）流水线

> 本文件是 `multiplatform-media-fetch` 的"效果层"扩展：现有"出文字"流水线（字幕→音频→OCR）拿到的是**内容**；对"价值在呈现效果/情绪/镜头语言"的视频（活人感教程、电影感旅拍、广告级成片、AI 短剧片段），内容稿不够，必须补**画面效果拆解**，最终产出"文稿 + 效果分析 + 可复用分平台提示词"。
> 2026-10-05 沉淀，2026-10-06 升级：**音频层分析升级为必选维度（双轨 = 画面层 + 音频层）**。用户明确要求：除视频画面外，**音频也要分析**——音频风格/文案规律/音画配合逻辑，回答"为什么这个音频适合这个视频"。
> 2026-10-07 升级：**镜头拆解前先答"导演动机"**（拆解 = 记录工具 + 解释动机，答不出动机算未完成）。方法论依据：抖音博主【猪猪侠_阿亮】导演思维与分镜生成原理 + 行业交叉验证，详见生产仓《导演思维与分镜生成SOP.md》。
> 来源标注四档沿用主技能（已查证/经搜索补充/博主一方说法/未经核实）。

## 〇、双轨原则（2026-10-06 用户硬性要求）

**凡是做视频分析的效果类视频，必须画面层 + 音频层双轨并行**，缺一不可：

- 画面层：叙事结构、情绪弧线、镜头语言、提示词反向工程（下文本文件主体）
- **音频层（新增必选）**：音频风格、文案规律、音乐参数、音画配合逻辑、可复用"音频配方"
- 很多视频的音频是**精心雕琢**的（旁白文案、配音声线、配乐情绪、音效节奏），其价值不亚于画面——尤其是"音视频结合非常好、音频应景"的标杆案例，要做最深。

### 借鉴不标准原则（2026-10-06 用户方法论，所有分析文档头部/尾部必须带）

**"制作故事的导演风格是不一样的，标准也是不同的。吸收这些知识是吸收借鉴，不要成为唯一标准。"**

- 每条被分析的视频（含用户认可的标杆）只代表**一种导演风格/一个样本**，不是唯一正确标准。
- 所有"可复用配方/提示词/音频配方"定位为**借鉴选项库成员**，并列呈现多方案（同一目标可以有多个参考：如珠宝故事感 = 70-100BPM 弦乐+钢琴 / 古风三层混搭 / 氛围电子……），不设"唯一最佳"。
- 反哺 SOP 时同样并列多方案；使用时按导演风格/受众/平台自行选择。

### 音频层分析框架（五问）

1. **音频构成拆解**：人声（旁白/配音/口播）+ 音乐（BGM）+ 音效（环境/拟音）各自占比与分工；是否有留白。
2. **文案规律**（人声部分）：句式结构（短句/排比/设问）、节奏（快慢/停顿/重音）、用词风格（书面/口语/古风/现代）、押韵或记忆点设计；直接摘录 2-3 句原文为证据。
3. **音乐参数**：BPM（快/中/慢）、调性（大调明亮/小调忧伤）、乐器（弦乐/钢琴/古筝/电子/打击）、情绪标签（史诗感/宁静/神秘/温暖/紧张）。
4. **音画配合逻辑**（核心，回答"为什么适合"）：情绪匹配（画面情绪↔音乐情绪）、节奏同步（音乐节拍↔镜头切换点）、音画锚点（高潮画面↔音乐高潮点）、人声与画面的起承转合对应、音效与关键动作的贴合。
5. **声音细节的事件触发机制（2026-10-06 用户观察）**：标杆片的细节（板凳声/环境音/人声哼气/叹气/轻笑）不是堆上去的，而是**由剧情/环境事件触发**——
   - 细节清单：逐个找出片中的拟音/环境音/人声微表情细节，标注出现时间点与对应画面事件
   - 触发逻辑：环境变化→新空间音（场景切换）；剧情变化→人声微反应（角色情绪节点）；没有画面依据的声音不该出现
   - 实现来源：标注逐条来自提示词触发词 / 模型能力（如 Seedance 音画同步）/ 后期人工拟音（四档来源）
   - 可复用方法：提炼"事件触发拟音/人声微表情"提示词写法模板（何时写、写在哪个镜头）
6. **可复用音频配方**：产出 `风格标签 + 参数（BPM/调性/乐器）+ 适配场景 + 参考案例`，供生产仓《音频选择与生成SOP.md》反哺。

### 音频获取方式

- 视频已下载：直接抽音轨（`ffmpeg -i video.mp4 -vn -acodec copy audio.m4a`）→ 听辨 + FunASR 转写人声
- 视频未下载：浏览器直读拿 douyinvod 直链 → curl 下载 → 同上
- 听辨为主、转写为辅：音乐参数（BPM/调性/乐器）靠听 + 资料交叉验证，标"未经核实"当无权威来源时

## 一、什么时候用（先判型）

| 视频类型 | 只出文字够吗 | 是否需要效果层 |
|---|---|---|
| 知识讲解（PPT/口播/教程步骤） | 够（字幕+音频+OCR） | ❌ 走现有流水线 |
| **活人感 / AI 成片效果演示**（"17万人围观的活人感教程"） | 不够——效果在画面 | ✅ 必须 |
| **风格呈现**（真人胶片电影感旅拍） | 不够——胶片感=色彩/颗粒/光线/运镜 | ✅ 必须 |
| 广告级短片 / 短剧片段 | 不够——情绪弧线与镜头是核心 | ✅ 必须 |
| **音画标杆片**（音视频结合特别好，如古风/史诗 AI 短片） | 不够——音频本身就是核心资产 | ✅ 必须（音频层做最深） |

**判定问题**：只看字幕/音频能否还原这个视频 80% 的价值？不能 → 走效果层。

## 二、流程总览（内容层 + 效果层并行）

```
视频
 ├─ 内容层（复用现有）：章节要点/字幕 → 音频转写 → OCR 兜底 → 内容文稿
 └─ 效果层（本文件）：
     ① 画面获取（下载抽帧 或 浏览器直读截图）
     ② 视觉读取（Read 逐帧看图，记录时间戳）
     ③ 效果拆解（叙事结构 + 情绪弧线 + 镜头语言）
     ④ 提示词反向工程（分平台可复用 prompt）
 合成 → 效果分析文档（含文稿 + 拆解 + 提示词）
```

## 三、画面获取（二选一）

**A. 能下载视频**（yt-dlp 可直下时）：
```bash
SKILL_DIR="<本技能安装目录>"
# 定时抽帧：教程/效果演示 5s 一帧；先跑通再按镜头补抽
ffmpeg -i video.mp4 -vf "fps=1/5,scale=1280:-1" frames/f%03d.jpg
```
→ 用 dHash 去重后逐帧 `Read`。

**B. 浏览器直读（抖音等无登录场景，首选）**：沿时间轴跳转 + 关键帧截图（参考 `douyin-browser-extract.md` 的免登录直读流程）：
1. 浏览器打开视频页，`bu.get_page_text()` 拿官方"章节要点"（等效字幕，内容层）；
2. **时间轴采样**：`bu.js("document.querySelector('video').currentTime = N")` 跳转到关键时间点（0s/3s/8s/每镜头切换点/结尾），`bu.screenshot()` 存图；
3. 本地 `Read` 逐帧看图（thumbnail_size 调大看细节）。

> 采样要点：开头 0-3s（hook）必截；每个镜头切换点必截；结尾 CTA 必截；中间按 5-10s 补。

## 四、效果拆解框架（四段式）

### 1. 叙事结构分段
按时间轴划分结构（参考 Viral Video Studio 模板，按实际时长调整）：
- **HOOK（0-3s）**：什么停住观众？开场画面/悬念/反差
- **SETUP**：前提/设定交代
- **CONFLICT**：张力/挑战/对比点
- **PEAK**：高潮/视觉最强点
- **TWIST / RESOLUTION**：转折或收束
- **CTA**：结尾引导（关注/评论/点击）

### 2. 情绪弧线与触发器
每段标注：**观众该有什么感受**——好奇 / 惊叹 / 幽默 / 冲击 / 向往 / 怀旧 / "想转给别人看"。
标出**情绪拐点**（哪个镜头让情绪翻转，参考 ReelMind 的 Tension Peak / Resolution Release 思路）。

### 2.5 导演动机先问（2026-10-07 升级，方法论见生产仓《导演思维与分镜生成SOP.md》）

拆解镜头前**先回答导演动机**，再记录工具——只记录镜头而答不出动机 = 拆解未完成：

- 这段导演想让观众**记住/感受**什么？（环境介绍 / 人物刻画 / 情绪传递 / 卖点证明 / 氛围种草）
- 视角策略：外部观察 / 主观视角 / 混合切换？视角是否随动机变化？
- 景别锁定的是谁、为什么锁？（锁近景=警觉/亲密；全景=环境/工具人一笔带过；特写=情绪最强点）
- 笔墨分配：谁是主角被重点刻画，谁是工具人？镜头数/时长是否向主角倾斜？
- 运镜速度 = 情绪速度？（慢跟=无力/郑重；快跟=紧张/兴奋；推镜=压力/觉悟；拉镜=孤立/后果）
- 长镜头/慢节奏出现在情绪浓烈处？（浓烈且难消化的情绪用长镜头记录）
- 构图是否用环境压制人物（大环境小人物=渺小无助）？

### 3. 镜头语言拆解（逐段一张小表）
| 维度 | 观察项 |
|---|---|
| 景别 | 特写/近景/中景/全景/大远景 |
| 运镜 | 推/拉/摇/移/跟/手持/固定/升降/环绕 |
| 转场 | 硬切/叠化/遮罩转场/匹配剪辑/甩镜 |
| 光线 | 自然光/逆光/侧光/顶光；暖调/冷调；高调/低调；硬光/柔光 |
| 色彩质感 | 色温/饱和度/对比度/颗粒/景深/胶片感（柯达/富士色调） |
| 主体人物 | 动作/表情/服装/道具/人景关系/焦点 |

### 4. 提示词反向工程（分平台可复用）
**公式**：`镜头景别 + 导演构图 + 人物设定 + 动作情绪 + 光影氛围 + 质感风格`

- **抽象词 → 物理词**（核心技巧）：把"高级感/活人感/电影感"翻译成模型能执行的物理描述。
  - 高级感 → 低饱和、高对比、暗部有细节、逆光轮廓光、景深浅
  - 活人感 → 微表情、眼神光、自然眨眼、头发碎发、皮肤纹理、非摆拍姿态（转头/整理头发）
  - 胶片感 → 颗粒、色偏（柯达 Portra 暖 / 富士冷）、高光溢出、暗角、35mm 镜头感
- **平台差异**：即梦/可灵/Seedance 的提示词措辞与参数（时长、运动幅度、画幅）按目标平台改写；写明该提示词基于哪个平台实测。

## 七、注意事项

1. **完整看 1-2 遍再写**：第一遍整体感知情绪节奏，第二遍按镜头拆解；截图不是代替观看，是辅助定位。
2. **不编造效果**：提示词标注"基于该视频视觉特征提炼，复现效果需实测"；博主的参数/模型说法标"博主一方说法"。
3. **画面优先于口播**：博主口播说的参数（如"用了 2.5"）与画面实际呈现冲突时，两处都记录，标注差异。
4. **与内容层共享素材**：同一批截图/字幕同时供文稿与效果层使用，不重复提取。
5. 效果类视频若**能下载**，优先下载本体再抽帧（画面质量远高于浏览器截图）；下载被拒才走浏览器直读。
