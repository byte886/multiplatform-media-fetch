# 视频转可阅读文档 SOP（video-to-reading-doc）

> 场景：单条视频（含 YouTube/B站/抖音）要形成**给人阅读的文档**——知识科普、选购对比、汇报型材料。区别于 A 路线的"成文"，本 SOP 强调**决策型结构 + 对比表格 + 格式化美化 + 来源可追溯**。
> 沉淀日期：2026-10-18（首例：《大陆用户投资美股全路径指南》，YouTube 88o9WU9LcYc）

## 一、触发与总流程

| 用户信号 | 处理 |
|---|---|
| "形成文稿/整理成文档/给我看/写成文章" | 走本 SOP |
| 只要视频/音频文件 | 走 `media_downloader.py`（B 纯下载） |
| 多链接同系列成体系 | 走 `batch_series_fetch.py`（C） |

五步流水线：**取文字 → 调研角度 → 定结构 → 撰写美化 → 交付归档**。

## 二、取文字（复用 A 路线决策链）

1. 先 `--list-subs` 探测字幕；命中手动中文字幕（zh-Hans 优先）→ `--subs` 下载并 `clean_subtitle.py` 清洗 → **直接拿 clean.txt 成文**。
2. 无字幕 → `--audio --smallest` 抽最小音轨 → `funasr_transcribe.py` 转写。
3. 连音轨都没有 → 才下 ≤720p 视频兜底 OCR（不自动跑）。

## 三、角度决策（关键一步：先定"给人读的目的是什么"）

**步骤 1：本地归类**——按 `article-pipeline.md` §4 的类型表判断视频类型：
教学 / 新闻评论 / 测评对比 / 经验观点 / 访谈 / 宣传 / Vlog。本 SOP 沉淀的首例为**测评/对比/选购指南**型。

**步骤 2：Google 调研交叉验证**（一次并行 ≤3 个 query，双语）：
- 中文："知识类视频 转成 文章 写作角度 结构 方法论"
- 英文："YouTube video to written article structure best practices"
- 常见共识（调研 2026-10 实测）：先决定角度（how-to / 观点文 / 要点汇总 / 深潜）；提取骨架而非逐句复述；4–7 个 H2 主点；每节"一句话承诺 → 解释 → 例子 → trade-off → 行动规则"；加对比表 + takeaway 框。

**步骤 3：合流定角度**。本地类型表与外部方法论重叠度最高的结构即为入选角度。首例选择：
> **决策型选购指南**（TL;DR 结论先行 → 路径/方案全景对比表 → 分维度对比 → 按人群决策表 → 速查要点），因为视频本质是"教读者选券商/选路径"，与"测评对比→结论先行→适合谁"结构完全吻合。

**决策记录**：在交付说明中向用户交代"为什么选这个角度"（本地归类 + 外部佐证 + 内容特征），不默默选择。

## 四、撰写规范（给人阅读，不是逐句转写）

1. **重构不复制**：提炼核心论点、支撑（数据/例子/步骤）、结论；去口播填充词（Hello大家好/点赞订阅等无信息语句），保留作者观点原意与关键原话。
2. **结论先行**：开头 TL;DR 一段话 + 一句话速查表，让读者 1 分钟掌握结论。
3. **对比用表格**：多方案对比一律横向表格（维度 × 方案），数字精确照录，不脑补。
4. **区分口径**：作者个人判断标"据作者称/作者观点"；客观事实与主观感受分开；作者主观评价（如"XX APP 不如 YY"）明确标注为主观。
5. **时间/数字复核**：相对时间（"去年夏天/今年5月"）必须换算成绝对年份再落笔，避免歧义。
6. **免责与来源**：涉及投资/医疗/法律等专业领域必须加来源声明 + 风险提示 + "不构成建议"；文末附视频 ID、频道、清洗字数、整理日期。
7. **字数**：口播 7000+ 字 → 阅读文档 2500–3500 字为宜（信息密度高、可扫读）。

## 五、格式化与美化规范（Markdown）

- 一级标题 + 来源元信息块（来源/类型/日期/时长，引用块展示）
- 目录（锚点链接）→ TL;DR 引用框 → 正文 H2/H3 层级
- 表格：表头加粗、关键数字加粗、对最优项加 🏆/✅ 标记
- 引用块（`>`）用于：作者观点原话、重要提示、takeaway
- 要点速查清单（✅/⚠️/⏳ 符号列表）收尾
- 中文排版：全角标点、数字与单位间空格（"12 万亿美元"）、专有名词中英文首次出现标注
