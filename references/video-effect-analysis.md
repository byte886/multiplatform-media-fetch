# 视频效果分析（效果呈现层）流水线

> 本文件是 `multiplatform-media-fetch` 的"效果层"扩展：现有"出文字"流水线（字幕→音频→OCR）拿到的是**内容**；对"价值在呈现效果/情绪/镜头语言"的视频（活人感教程、电影感旅拍、广告级成片、AI 短剧片段），内容稿不够，必须补**画面效果拆解**，最终产出"文稿 + 效果分析 + 可复用分平台提示词"。
> 2026-10-05 沉淀，来源标注四档沿用主技能（已查证/经搜索补充/博主一方说法/未经核实）。

## 一、什么时候用（先判型）

| 视频类型 | 只出文字够吗 | 是否需要效果层 |
|---|---|---|
| 知识讲解（PPT/口播/教程步骤） | 够（字幕+音频+OCR） | ❌ 走现有流水线 |
| **活人感 / AI 成片效果演示**（"17万人围观的活人感教程"） | 不够——效果在画面 | ✅ 必须 |
| **风格呈现**（真人胶片电影感旅拍） | 不够——胶片感=色彩/颗粒/光线/运镜 | ✅ 必须 |
| 广告级短片 / 短剧片段 | 不够——情绪弧线与镜头是核心 | ✅ 必须 |

**判定问题**：只看字幕/音频能否还原这个视频 80% 的价值？不能 → 走效果层。

## 二、流程总览（内容层 + 效果层并行）

```
视频
 ├─ 内容层（复用现有）：章节要点/字幕 → 音频转写 → OCR 兜底 → 内容文稿
 └─ 效果层（本文件）：
     ① 画面获取（下载抽帧 或 浏览器直读截图）
     ② 视觉读取（Read 逐帧看图，记录时间戳）
     ③ 效果拆解（叙事结构 + 情绪弧线 + 镜头语言）
     ④ 提示词反向工程（分平台可复用 prompt）
 合成 → 效果分析文档（含文稿 + 拆解 + 提示词）
```

## 三、画面获取（二选一）

**A. 能下载视频**（yt-dlp 可直下时）：
```bash
SKILL_DIR="<本技能安装目录>"
# 定时抽帧：教程/效果演示 5s 一帧；先跑通再按镜头补抽
ffmpeg -i video.mp4 -vf "fps=1/5,scale=1280:-1" frames/f%03d.jpg
```
→ 用 dHash 去重后逐帧 `Read`。

**B. 浏览器直读（抖音等无登录场景，首选）**：沿时间轴跳转 + 关键帧截图（参考 `douyin-browser-extract.md` 的免登录直读流程）：
1. 浏览器打开视频页，`bu.get_page_text()` 拿官方"章节要点"（等效字幕，内容层）；
2. **时间轴采样**：`bu.js("document.querySelector('video').currentTime = N")` 跳转到关键时间点（0s/3s/8s/每镜头切换点/结尾），`bu.screenshot()` 存图；
3. 本地 `Read` 逐帧看图（thumbnail_size 调大看细节）。

> 采样要点：开头 0-3s（hook）必截；每个镜头切换点必截；结尾 CTA 必截；中间按 5-10s 补。

## 四、效果拆解框架（四段式）

### 1. 叙事结构分段
按时间轴划分结构（参考 Viral Video Studio 模板，按实际时长调整）：
- **HOOK（0-3s）**：什么停住观众？开场画面/悬念/反差
- **SETUP**：前提/设定交代
- **CONFLICT**：张力/挑战/对比点
- **PEAK**：高潮/视觉最强点
- **TWIST / RESOLUTION**：转折或收束
- **CTA**：结尾引导（关注/评论/点击）

### 2. 情绪弧线与触发器
每段标注：**观众该有什么感受**——好奇 / 惊叹 / 幽默 / 冲击 / 向往 / 怀旧 / "想转给别人看"。
标出**情绪拐点**（哪个镜头让情绪翻转，参考 ReelMind 的 Tension Peak / Resolution Release 思路）。

### 3. 镜头语言拆解（逐段一张小表）
| 维度 | 观察项 |
|---|---|
| 景别 | 特写/近景/中景/全景/大远景 |
| 运镜 | 推/拉/摇/移/跟/手持/固定/升降/环绕 |
| 转场 | 硬切/叠化/遮罩转场/匹配剪辑/甩镜 |
| 光线 | 自然光/逆光/侧光/顶光；暖调/冷调；高调/低调；硬光/柔光 |
| 色彩质感 | 色温/饱和度/对比度/颗粒/景深/胶片感（柯达/富士色调） |
| 主体人物 | 动作/表情/服装/道具/人景关系/焦点 |

### 4. 提示词反向工程（分平台可复用）
**公式**：`镜头景别 + 导演构图 + 人物设定 + 动作情绪 + 光影氛围 + 质感风格`

- **抽象词 → 物理词**（核心技巧）：把"高级感/活人感/电影感"翻译成模型能执行的物理描述。
  - 高级感 → 低饱和、高对比、暗部有细节、逆光轮廓光、景深浅
  - 活人感 → 微表情、眼神光、自然眨眼、头发碎发、皮肤纹理、非摆拍姿态（转头/整理头发）
  - 胶片感 → 颗粒、色偏（柯达 Portra 暖 / 富士冷）、高光溢出、暗角、35mm 镜头感
- **平台差异**：即梦/可灵/Seedance 的提示词措辞与参数（时长、运动幅度、画幅）按目标平台改写；写明该提示词基于哪个平台实测。

## 六、注意事项

1. **完整看 1-2 遍再写**：第一遍整体感知情绪节奏，第二遍按镜头拆解；截图不是代替观看，是辅助定位。
2. **不编造效果**：提示词标注"基于该视频视觉特征提炼，复现效果需实测"；博主的参数/模型说法标"博主一方说法"。
3. **画面优先于口播**：博主口播说的参数（如"用了 2.5"）与画面实际呈现冲突时，两处都记录，标注差异。
4. **与内容层共享素材**：同一批截图/字幕同时供文稿与效果层使用，不重复提取。
5. 效果类视频若**能下载**，优先下载本体再抽帧（画面质量远高于浏览器截图）；下载被拒才走浏览器直读。
